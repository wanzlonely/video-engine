# Remotion — Full Video Engine

Render video sepenuhnya lewat **Remotion** (React + timeline).

## Lokal

```bash
cd remotion
npm install
npm run studio          # preview interaktif
npm run render          # export MP4 → out/zanzibar.mp4
```

## GitHub Actions

Workflow: `.github/workflows/render-remotion.yml`

- Trigger: push ke `remotion/**` atau manual
- Artifact: `remotion-video` (MP4)
